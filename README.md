# grocery-sales-analysis
An Analysis of Grocery Sales from 2010-2012 using SQL.

## The Project's Objective
Undertake a thorough analysis of the grocery sales' data using SQL to gather actionable insights and improve strategic focus.

#### Specifications
Data Source - Import the data from the provided CSV file.
Data Quality - Cleanse and address data quality issues before conducting analysis.
Scope - Concentrate on the supplied data only; extrapolation for previous and future years is unnecessary.
